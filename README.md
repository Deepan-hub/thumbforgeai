# ThumbForge AI 🎨

> AI-powered YouTube thumbnail generator that helps content 
> creators make professional, click-worthy thumbnails in seconds.

## 🌐 Live Demo
**(https://aithumbforge.netlify.app/)**

## ✨ Features

- 🤖 **AI-Powered Generation** — Generate professional 
  thumbnails using AI instantly
- 💳 **Credit System** — Basic (₹2,499), Pro (₹6,599), 
  Enterprise (₹16,599) plans
- 🎨 **Multiple Templates** — Standard and Premium quality
- 📺 **4K Resolution** — Crystal clear thumbnail output
- 🔐 **User Authentication** — Secure login and accounts
- 📁 **My Generations** — History of all your thumbnails
- 📊 **A/B Testing Tools** — Test which thumbnail performs better
- 🏷️ **Brand Kit Analysis** — Keep your brand consistent
